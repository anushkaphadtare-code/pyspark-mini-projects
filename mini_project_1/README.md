# Retail Sales Analysis using PySpark and Delta Lake

## Project Overview

This project demonstrates a simple retail sales analytics workflow using **PySpark and Delta Lake in Databricks Free Edition**. The goal is to transform retail order data into meaningful sales insights by calculating revenue, aggregating sales metrics, joining datasets, and storing the results as Delta tables.

## Technologies Used

- **Apache Spark (PySpark):** Data transformation and aggregation
- **Databricks Free Edition:** Cloud-based development environment
- **Delta Lake:** Storage of processed data in Delta tables
- **SQL:** Querying and validating analytical tables

## Dataset

The project uses three sample datasets:

- **Orders:** Order ID, customer ID, product ID, order date, quantity, and unit price.
- **Products:** Product ID, product name, category, and product price.
- **Customers:** Customer ID, customer name, and region.

## Project Workflow

### 1. DataFrame Creation

Created PySpark DataFrames for orders, products, and customers using explicitly defined schemas.

### 2. Data Validation

Performed initial checks on the datasets, including checking for null values, duplicate rows, and duplicate product and customer IDs.

### 3. Revenue Calculation

Created a new `total_amount` column to calculate the revenue generated by each order.

**Formula:**

`total_amount = quantity × unit_price`

### 4. Product-Level Sales Analysis

Grouped order data by product to calculate:
- Total revenue generated by each product
- Number of orders for each product

Joined the aggregated results with product details and sorted products by total revenue in descending order.

### 5. Regional Sales Analysis

Joined orders with customer details and grouped the data by region to calculate:
- Total revenue generated by each region
- Number of orders from each region

### 6. Delta Table Creation

Stored the processed and aggregated datasets as Delta tables in Databricks.

| Table Name | Description |
|---|---|
| `retail_orders_silver` | Order-level data with calculated revenue |
| `retail_product_revenue_gold` | Product-level revenue and order metrics |
| `retail_region_revenue_gold` | Region-level revenue and order metrics |

The tables follow a simplified **Silver and Gold layer approach**:
- **Silver:** Transformed order-level data enriched with a calculated revenue column.
- **Gold:** Aggregated datasets designed for sales analysis and reporting.

## Key Learnings

- Creating PySpark DataFrames with explicit schemas
- Performing data validation checks
- Using PySpark column expressions and transformations
- Applying `groupBy()` and aggregation functions
- Joining multiple DataFrames
- Sorting aggregated results
- Saving and querying Delta tables in Databricks
- Understanding the purpose of Silver and Gold layers in a data pipeline

Built a basic end-to-end retail sales analytics workflow that transforms order data into product-level and regional sales summaries and persists the results as Delta tables for further analysis.
