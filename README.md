# PySpark Mini Projects

A collection of hands-on mini-projects built using **PySpark** to develop practical skills in distributed data processing, data transformation, analytics, and data engineering.

Each project focuses on a specific concept or workflow, with an emphasis on practical implementation and learning by building.

## 🛠️ Tech Stack

- **Apache Spark (PySpark)** — Distributed data processing and transformations
- **Databricks Free Edition** — Cloud-based development environment
- **Delta Lake** — Reliable storage and management of processed data
- **SQL** — Data querying and analysis

## 📂 Projects

### 1. Retail Sales Analysis

**Folder:** `retail_sales_analysis/`

A retail sales analytics project that uses PySpark to transform order data, calculate revenue, and generate product-level and regional sales summaries.

**Key Concepts:**

- Creating DataFrames with explicit schemas
- Data validation and duplicate checks
- Column transformations and revenue calculation
- Grouping and aggregating sales data
- Joining orders, products, and customers
- Storing processed data in Delta tables
- Understanding Silver and Gold data layers

**Technologies:** PySpark, Databricks, Delta Lake

*Status: Completed*
